QB函数 · 抽象函数新定义

第21题 · 不等式恒成立 + 充要条件 · 高中数学
题目

已知函数 y = f(x)，x ∈ D，若对于定义域 D 内任意实数 x, y，不等式

f(x) + f(y) ≥ f(xy)

都成立，则称函数 y = f(x)，x ∈ D 是 QB 函数。

(1) 判断函数 f(x) = −x² 是否是 QB 函数，并说明理由；

(2) D = (0, +∞)，若 g(x) = log½(ax) 是 QB 函数，求实数 a 的取值范围；

(3) 已知 h(x) = aˣ（a > 0，a ∈ R），证明："函数 y = h(x) 是 QB 函数" 的充要条件是 "a = 1"。

📚 核心知识点详解

① QB 函数定义 —— 读懂"新定义"题

对任意 x, y ∈ D，都有 f(x) + f(y) ≥ f(xy)

意思是：两个点的函数值之和，不小于这两个点乘积处的函数值。它是对"函数增长快慢"的一种约束。

💡 这类"新定义"题不用怕，本质就是：把题目给的不等式，套到具体函数上，验证它是否恒成立（判断题）或反过来求参数（求参题）。

② 判断 / 求参的核心方法

判断题（第1小题）：只要找到一个反例 (x, y) 使 f(x)+f(y) < f(xy)，就否定。常取 x = y = 1、x = y = 0 等简单值试探。

求参题（第2小题）：把具体函数代入不等式，利用运算性质（如 log(xy) = log x + log y）化简，再分离参数。

证明题（第3小题）：充要条件 = 充分性 + 必要性，必要性常用反证法 / 构造反例。

③ 关键陷阱 —— 定义域决定反例的取法

第(3)小题 h(x) = aˣ 的定义域是 全体实数 R（含负数）。

若 a > 1，取 x = y = n（n 足够大），aⁿ 指数爆炸，aⁿ + aⁿ < an²；

若 0 < a < 1，取 x = −1，y = n（n 足够大），a⁻¹ + aⁿ < a−n（因 aⁿ → 0）。

⚠️ 很多人只取正数 x、y 试探，就会漏掉"负自变量"带来的反例，得出错误结论。

📝 解题过程 · 分步拆解

第(1)小题：f(x) = −x² 是否 QB 函数？

💚 最简单：取特殊值找反例

策略：判断「不是 QB 函数」，最省事的办法是找一组 x、y 让不等式不成立。优先试 x = y = 1（好算）。

需验证 −x² − y² ≥ −(xy)² 是否恒成立，即 x² + y² ≤ x²y²。

取 x = y = 1：左 = 1 + 1 = 2，右 = 1，2 ≤ 1 不成立。

⚠️ 易错点：别去硬证「x² + y² ≤ x²y² 对所有 x,y 成立」——它根本不成立，直接举一个反例就够。

答案(1)：f(x) = −x² 不是 QB 函数（反例 x = y = 1）

第(2)小题：g(x) = log½(ax) 求 a

💚 最简单：对数法则直接拆（这问就这么解）

第一步：用对数法则 log(MN) = logM + logN，把 g 拆开：

g(x) = log½(ax) = log½a + log½x

第二步：算出 g(x) + g(y) 和 g(xy)：

g(x) + g(y) = 2log½a + log½(xy)　　g(xy) = log½a + log½(xy)

第三步：代入 QB 不等式，两边消掉 log½(xy)：

2log½a + log½(xy) ≥ log½a + log½(xy)　⟹　log½a ≥ 0

第四步：解 log½a ≥ 0。底 ½ 比 1 小，对数随 x 增大而减小，所以 log½a ≥ 0 = log½1 ⟺ a ≤ 1，又 a > 0（真数 ax 必须大于 0），故 0 < a ≤ 1。

⚠️ 易错点：底 ½ < 1，解 log½a ≥ 0 时不等号要反向，得 a ≤ 1，别写成 a ≥ 1。

答案(2)：a ∈ (0, 1]

第(3)小题：证明 h(x) = aˣ 是 QB 函数 ⇔ a = 1

⏰ 这是本卷压轴题（5 分），用到了「反证法」和「取一个足够大的数」的想法。如果卡住，先把前两问的分拿稳，这问看懂思路即可。

「充要条件」要证两个方向：

方向一 · 充分性：a = 1 直接验证

a = 1 时 h(x) = 1ˣ = 1（1 的任何次方都等于 1），于是

h(x) + h(y) = 1 + 1 = 2 ≥ 1 = h(xy)

恒成立，所以 h(x) = 1 是 QB 函数。✓

方向二 · 必要性：反证法（a ≠ 1 会矛盾）

用反证：假设 a ≠ 1（即 a > 1 或 0 < a < 1），想办法找一个 (x, y) 让不等式不成立，就能否定它。

· 若 a > 1：取 x = y = n（n 是一个很大的数）。左边 h(n)+h(n) = 2aⁿ，右边 h(n²) = an²。因为 a > 1，n² 比 n 大得多，an² 会远远超过 2aⁿ，所以 2aⁿ < an²，不等式不成立，矛盾。

· 若 0 < a < 1：取 x = −1，y = n。左边 h(−1)+h(n) = a⁻¹ + aⁿ = 1/a + aⁿ（aⁿ 越来越小、接近 0），右边 h(−n) = a−n = 1/aⁿ（n 越大这个数越大）。当 n 足够大时，右边远超左边，不等式不成立，矛盾。

两种情况都矛盾，说明假设「a ≠ 1」是错的，所以只能是 a = 1。✓

答案(3)：充要条件是 a = 1
